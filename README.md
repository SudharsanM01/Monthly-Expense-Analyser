# AI-Based Monthly Expense Analysis and Smart Savings Recommendation System

A Python Tkinter + SQLite desktop application for recording expenses, analyzing monthly spending, comparing months, checking budgets, and generating smart savings recommendations.

## Features

- User registration and login
- Add and delete expenses
- Date, category, description and amount fields
- Monthly expense filtering
- Category-wise spending analysis
- Monthly budget tracking
- Previous-month comparison
- AI-style smart savings recommendations
- SQLite local database
- No external AI API required

## Technologies

- Python
- Tkinter
- SQLite
- Git / GitHub

## How to Run

1. Install Python 3.
2. Open this folder in VS Code.
3. Open the terminal.
4. Run:

```bash
python main.py
```

The application automatically creates `expenses.db` when it starts.
